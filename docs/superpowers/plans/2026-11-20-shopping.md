# Shopping Implementation Plan

**Goal:** Complete the shopping journey through checkout review, with proposed pricing and an accurate persistent cart.
**Architecture:** Catalogue owns offers; pure cart utilities validate persisted quantities and calculate cents. A shared React provider owns cart state, drawer and notices. Reusable add/quantity/line controls serve cards, dialogs and checkout. Checkout keeps customer information in memory only.
**Stack:** Existing React, TypeScript, Vite, React Router, Lucide, Node tests and Playwright. No new dependencies.
**Spec:** docs/superpowers/specs/2026-11-20-shopping-design.md

1. Add failing tests for proposed catalogue offers, cart normalization and quantity bounds, integer-money calculations, delivery thresholds and checkout request validation.
2. Add offers and pure shopping utilities; run tests. Build provider, cart drawer, quantity and add controls; replace header search and connect product surfaces.
3. Add checkout details/review route, accessible responsive styling, direct-route prerendering and consistent ordering FAQ/guide copy. Keep existing enquiry functions.
4. Build and run browser journeys at 375/768/1280px, including malformed storage, refresh, all entry points, validation, review/edit, empty cart, keyboard and axe. Inspect screenshots; fix findings and rerun relevant checks.
